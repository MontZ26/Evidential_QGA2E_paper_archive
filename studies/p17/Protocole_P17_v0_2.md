## D. Gain marginal d'évidence (définition opérationnelle, EXACTE, sans approximation)
**Constat :** pour la combinaison de Dempster normalisée de supports simples, Bel({t}) = m({t}) et Pl({t}) = m({t}) + m_p(Θ) ; la largeur d'intervalle d'un singleton vaut m_p(Θ) pour toutes les équipes. L'ignorance « d'un individu » par largeur d'intervalle est donc constante dans une génération et ne discrimine pas (vérifié par test).
**Ensemble de référence S :** premier front non dominé **sur les 3 objectifs réels** de la population parente au début de la génération (les mêmes sources que la cible). Candidats évalués : les 2·POP = 80 individus (parents + enfants). S est un multiensemble d'individus ; un enfant de génotype identique à une source s'y ajoute comme doublon (similarité 1 ≥ σ, rabais α complet).
**Règle sans double comptage (leave-one-out) :** pour un candidat x, S_{-x} = S \ {x} si x est une source (même individu), sinon S. Incertitude u(·) = moyenne sur les patients modifiables de m_p(Θ) du modèle DA (évidentiel) ou de l'entropie de la cible probabiliste V0c (probabiliste).
**Gain :** G(x) = u(S_{-x}) − u(S_{-x} ∪ {x}). Pour un non-membre : u(S) − u(S ∪ {x}) ; pour un membre : u(S \ {x}) − u(S). G > 0 : x apporte de l'évidence (réduit l'incertitude). **Objectif de sélection : minimiser U(x) = −G(x)** (l'ignorance marginale la plus basse gagne).
**Calcul exact vectorisé (DA) :** avec ω = −ln(1 − w), ñ_{t,p} et α_i(p) = 1/(1 + λ(nM_i(p) − 1)) comme en P15 (σ = 0,7, λ = 1), D_p = 1 + Σ_t (e^{ω ñ_{t,p}} − 1), m_p(Θ) = 1/D_p. Ajout de x : seule l'équipe t = x_p du patient p change ; δñ = α_x(p) + Σ_{i voisins de x, x_i(p) = x_p} [1/(1 + λ nM_i) − α_i] avec α_x(p) = 1/(1 + λ · nb de voisins de x qui s'accordent en p) ; D'_p = D_p + e^{ω ñ_{x_p,p}} (e^{ω δñ} − 1). Retrait d'un membre : δñ = −α_x(p) + Σ_{i voisins} [1/(1 + λ(nM_i − 2)) − α_i]. Voisinage : similarité de génotype s_ij = proportion de patients à même équipe ≥ σ = 0,7, soi exclu ; égalités à la même opération numérique que `p15.eff_counts`. **Test d'exactitude :** erreur maximale, quantile 99,9 % et nombre de classements différents contre le recalcul complet par `p15.da_model` sur ensembles aléatoires (membres et non-membres), tolérance 1e-9, zéro classement différent.
**Pendant probabiliste :** cible V0c : q_t = w n_t/N + (1 − w) U_t (U uniforme sur les équipes admissibles) ; u = entropie moyenne de q sur les patients modifiables ; mêmes S, même règle leave-one-out (test d'exactitude contre recalcul via `p7.population_model(…, "V0c")`).

## E. Mécanismes de sélection (sélection environnementale seulement ; archive et HV sur les 3 objectifs)
Patch d'exécution de `X.select_next` (try/finally) ; modules gelés inchangés ; la sélection initiale (taille POP → POP) passe sans modification. Le tri non dominé et la distance de crowding du code (`non_dominated_sort`, `crowding_dist`) acceptent un nombre quelconque d'objectifs à minimiser (vérifié dans le code).
- **SEL4 :** tri non dominé sur [f1, f2, f3, U] ; crowding à 4 objectifs selon la fonction existante (normalisation par l'étendue + 1e-9 ; ex æquo résolus par l'ordre stable de `sorted`, indices croissants). Alerte de diagnostic (jamais un critère d'échec) : part des 80 candidats dans le premier front à 4 objectifs > 60 %.
- **SELW (secondaire) :** rang_F = numéro de front du tri à 3 objectifs (1 = meilleur, ex æquo partagent le numéro) ; rang_U = rang moyen croissant de U (1 = U le plus petit) ; normalisation r → (r − 1)/(max − 1) (0 si max = 1) ; score = (1 − λ) rang_F + λ rang_U avec **λ = 0,5 fixé** ; sélection des POP scores les plus bas, ex æquo par distance de crowding à 3 objectifs décroissante puis indice croissant.
- **SELL (Tier 2, non exécuté) :** U départage les candidats de même front et même crowding, égalité exacte à 1e-12.
- **SELR (contrôle de SEL4) :** score U_r ~ Uniforme(0,1), indépendant des génotypes, tiré pour chacun des 80 candidats à chaque génération, fixe pendant la sélection, flux aléatoire propre `P.rs(sc, seed, "p17_selr")` ; même mécanisme que SEL4 (4e objectif).
- Diagnostics par génération (bras de sélection) : part du premier front à 4 objectifs ; divergence de sélection = 1 − |sél. ∩ sél. à 3 objectifs| / POP ; gain moyen des sélectionnés et des non sélectionnés ; taille de S.

## I. Effectif et puissance
Écart-type observé des contrastes de HV par graine (moyenne sur 6 scénarios) dans P14 (n = 200) : E−Dp 0,0109 ; E−Dg 0,0108 ; Dg−Dp 0,0108 (ce sont des contrastes appariés par graine). Pour l'équivalence (IC ⊂ ±0,005) la demi-largeur de l'IC à 99 % vaut environ 0,0028 à n = 100 pour σ = 0,0109 : l'équivalence n'est atteignable que si l'effet vrai est inférieur à environ 0,002 ; pour P3 (différence de différences) σ est supposé ≈ 0,015 (√2 × 0,0109, hypothèse à vérifier a posteriori). **Simulation de puissance exécutée avant le gel** (`p17_power.json` ; 400 répétitions, bootstrap 1 000, n = 100, niveau 99 %, marge 0,005 ; données simulées, aucune donnée P17) : pour σ = 0,0109, effet vrai 0,005 : P(supériorité) = 0,98 ; effet 0 : P(équivalence) = 0,95 ; effet 0,002 : P(équivalence) = 0,62 ; pour σ = 0,0154 (cas de P3), effet 0,005 : P(supériorité) = 0,80 ; effet 0 : P(équivalence) = 0,54. L'équivalence de P3 est donc peu probable à établir même sans effet vrai ; elle sera rapportée comme non concluante si l'IC dépasse ±δ.
