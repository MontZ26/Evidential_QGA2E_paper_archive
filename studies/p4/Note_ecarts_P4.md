# P4 — notes d'écarts et de documentation (7 novembre 2026, rédigées pendant le run confirmatoire; le code et le protocole gelés ne sont PAS modifiés)

1. **Consommation du flux "xm_cross".** Le protocole (v0.4.1 §2.1, repris par v0.5) décrit un tirage de Bernoulli par enfant, puis un tirage par patient *si* le croisement réussit. Le code gelé effectue toujours les deux tirages (u = rand(), take = rand(n_p)), puis n'utilise `take` que si u < p_c. Les nombres inutilisés sont ignorés: la loi du croisement est identique (un Bernoulli p_c, puis un choix 0,5 par patient). Seule la consommation du flux dédié "xm_cross" diffère de la lettre du protocole; elle est constante par enfant, ce qui garantit que changer p_c ne décale pas les tirages des autres flux. Aucun autre flux n'est concerné. À déclarer dans le papier comme précision d'implémentation; aucune modification du code gelé.
2. **En-têtes v0.4.1.** Les en-têtes de p4.py, p4_run.py et an_p4_final.py citent v0.4.1, version sous laquelle le code a été écrit. v0.5 ne change que §5 (n = 300, amendement après pilote) et ajoute §9d (dont la déclaration de reconstruction). Les règles d'algorithme, de réglage, d'hypothèses et d'analyse sont celles de v0.4.1.
3. **Compteurs de mutation.** QGA-XM-E: `selected` = patients mutables (≥ 2 équipes) tirés, `effective` = échanges changeant les angles, `noeffect` = échanges d'angles égaux. NSGA-II: `selected` = gènes tirés, `effective` = changement d'équipe, `noeffect` = patient à une seule équipe. Les définitions diffèrent; le rapport final les présentera séparément, sans taux comparés directement.
4. **Reprise du run.** Le run confirmatoire a été interrompu une fois (4 instances terminées) et relancé avec le même code; chaque lancement vérifie le gel (`verify_freeze`) avant de calculer. Aucun résultat n'a été mélangé entre versions (une seule version gelée, un seul fichier de résultats). Consigné dans p4_run_notes.txt.
5. **Contrôles d'entrée de l'analyse.** Ajout d'un script séparé, p4_precheck.py (non gelé, n'altère ni l'analyse ni les données), exécuté avant l'analyse unique: gel, plage et nombre de seeds, six scénarios, onze algorithmes, budgets, valeurs finies dans [0,1].
6. **Dossier de reproductibilité.** p1m.py, p2s2.py, p3.py d'origine (SHA identiques à P3); run_p1m.py et ablation_loo.py reconstruits (vérifiés par non-régression exacte sur les fronts P3 stockés). Tests réexécutables avec `python3 p4_tests.py A B C D E`.
